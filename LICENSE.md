# Licensing status

There is **no single blanket license** applied to every file in this repository.

Reconstructed game code, historical-derived material, independently written utilities, and third-party/open-source lineage have different provenance and may have different legal/licensing requirements. See `PROVENANCE.md` and `THIRD_PARTY_NOTICES.md`.

Until individual copyright holders/contributors select an explicit license for newly written project utilities, those files should be treated under their stated file-level notices or, if none is present, with no additional license grant implied by this repository.

Do not add a repository-wide MIT/GPL/BSD license over the original/reconstructed game material without first separating the independently authored portions and reviewing the applicable rights.
