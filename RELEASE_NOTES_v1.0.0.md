# Alien vs Predator (Atari Jaguar) reconstructed source — v1.0.0

First stable preservation release of the completed code-only source reconstruction.

## Highlights

- 100% ordinary 68000 semantic/source coverage.
- Canonical World retail cartridge reproducibility target closed.
- Exact full-ROM verification: `4,194,304` bytes, zero differences.
- Canonical SHA-256: `b31ca5c2415881ce50d0c076d327297547214a6240f0058b0f225a74f7ce440b`.
- No retail audiovisual/resource assets or non-code retail data distributed.
- Separate Atari Jaguar 1994 toolchain reconstruction dependency.
- One-command `build.sh` front end.
- Contributor-facing engine, format, audio/GPU/DSP and build documentation.
- Explicit licensing, credits, third-party notices and provenance.

## Release policy

This release is the preservation baseline. SDK and PC-port work should build on it rather than silently altering retail behavior in the baseline.
