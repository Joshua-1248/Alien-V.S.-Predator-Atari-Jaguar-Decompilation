# Weapons

Weapon behavior is part of the player/gameplay state handled by the reconstructed 68000 program, with audiovisual presentation delegated to the corresponding renderer/audio paths.

The preservation baseline retains original firing cadence, state transitions, ammunition behavior and animation/gameplay synchronization. Future enhancements should be opt-in.

Modding tools should prefer native values/units and preserve exact ranges rather than silently converting values to a different model.
