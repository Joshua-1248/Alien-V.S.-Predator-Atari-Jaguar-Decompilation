# Third-party notices

This repository intentionally avoids applying one blanket license to historical or reconstructed material with different provenance.

## Alien vs Predator / Atari Jaguar

Alien vs Predator and its original game content are works of their respective rights holders. No retail ROM or proprietary audiovisual assets are distributed here.

## GNU GCC

The historical compiler lineage is GNU GCC 2.5.8 with the Atari ST Patchlevel 1 target changes. GCC is GNU software and must be redistributed only under its applicable GNU license terms. GCC source/binaries are not bundled in this source repository.

## Atari Jaguar tools

MadMac, ALN, JagCrypt and other period Atari Jaguar tools/material retain their original authorship and any applicable notices. The public repositories should prefer independently written compatibility/reconstruction code unless redistribution rights for a historical file are clear.

## Eric R. Smith / mit2mot / unzip lineage

Historical documentation connects Eric R. Smith's `mit2mot` and unzip work with AvP's 1994 build/integration. Reconstructed compatibility code does not claim authorship of Smith's original historical implementation.

## gzip / DEFLATE

Compression compatibility code reproduces historical gzip 1.2.4-era output behavior. Any directly incorporated third-party source must retain its original license header; the current Python compatibility utilities are maintained separately from original gzip source.

## Adding third-party material

Do not remove upstream notices. Add the upstream license text under `LICENSES/` when redistribution requires it and document the file/component here.
